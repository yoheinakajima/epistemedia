# Philosophy inquiry application profile

`epistemedia.philosophy_inquiry` is a reversible, non-normative adapter for provenance-bearing argument inquiries. It does not modify protocol schemas, accepted knowledge, policies, governance, the public site, or network routes.

The validator keeps propositions separate from actor assertions, premise roles separate from textual evidence, logical works separate from snapshots and exact spans, inferential support separate from evidential support, and policy-relative evaluation separate from truth. Source spans validate by SHA-256; all references must close; unordered collections canonicalize before bundle identity is calculated.

Before explicit release approval, the public projection is a constant fictional capability profile. Private counts, text, ordering, topology, rankings, hashes, and mutations cannot affect it. The included lighthouse fixture exists only to prove software behavior.

The Python read adapter exposes overview, candidate-funnel, branch, and evaluation resources from one validated projection. New CLI, REST, MCP, site, or normative integration requires a separate authority contract.
