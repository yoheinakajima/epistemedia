# Brand Architecture

## Epistemedia

**Knowledge that can show its work.**

Epistemedia is the umbrella project, public knowledge network, website, institution, and community-facing product.

Recommended descriptor:

> An open, federated knowledge network for humans and agents.

## Epistemic Mesh

Epistemic Mesh is the protocol beneath Epistemedia: the event model, provenance graph, federation rules, disclosure pipeline, policy evaluation, and machine governance substrate.

## Names

| Name | Role |
| --- | --- |
| Epistemedia | Public project and network |
| Epistemic Mesh | Protocol and architecture |
| Epistemedia Node | A standalone sovereign implementation |
| Epistemedia Commons | The default public realm, when a realm-specific distinction is needed |
| `epistemic_mesh` | Low-level Python protocol module where retained for compatibility |
| `epistemedia` | Public CLI and integration package |

The repository is named `epistemedia`. Historical Epistemic Mesh design and implementation records remain intact rather than being rewritten.

## Positioning

Epistemedia is not differentiated by using AI to draft more encyclopedia pages. It changes the canonical knowledge object:

- sourced epistemic history rather than generated pages;
- policy-explicit projections rather than one canonical narrative;
- evidence-lineage independence rather than source or agent count;
- sovereign aligned realms rather than one global ontology;
- executable constitutional governance rather than popularity voting;
- proof-carrying compilation rather than hidden synthesis.

## Voice

Clear, exact, curious, non-dogmatic, and inspectable. Avoid declaring a final universal truth when the system actually presents a policy-relative evaluation. Prefer concrete source, scope, time, and uncertainty language.
