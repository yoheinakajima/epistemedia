activate hosted API or MCP services, add a future case, or claim deployment before Pages and live
route read-back. Case 003 is a bounded historical score-and-comparison case; Case 004 is a bounded
history and propagation-lineage case, not a universal law of communication.

relations displayed a generic note and source cards while leaving the resolved proposition,
