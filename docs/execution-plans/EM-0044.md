# EM-0044 - Public layout density correction

## Problem

The EM-0043 Register adapter is materially clearer than the prior site, but the deployed desktop
layout underuses the canvas. At a 1692 px viewport, `main` is 1080 px wide and begins 306 px from
the left edge. Repeated 112 px metadata rails then move human content another 128 px inward. The
homepage mission bridge leaves its action in the reading column, and the About problem section
stacks all three paragraphs in column two, leaving a visibly empty rail under the heading.

## Bounded correction

1. Increase the shared desktop register from 1080 px to 1320 px while retaining 16 px minimum
   viewport gutters and the existing prose measures.
2. Reduce the repeated metadata register from 112 px to 88 px.
3. Give the homepage mission bridge a useful 220 px heading/action rail and a fluid reading column.
4. Distribute the three existing About problem paragraphs over two reading columns, with the final
   paragraph spanning both, while retaining the existing source order and text.
5. Keep the established mobile collapse at 760 px and explicitly reset editorial grid placement.

## Validation
