# Epistemedia v0.2.0

This release establishes Epistemedia as the public project and Epistemic Mesh as its underlying protocol architecture.

## Public interface

- deterministic human site and topic projections;
- clean Markdown twins;
- root and scoped `llms.txt` indexes;
- disclosure-safe public catalog and search index;
- OpenAPI-described read API;
- read-only MCP resources and tools;
- local-first CLI with optional remote reads;
- discovery, status, sitemap, security, and reproducibility manifests.

## Operating substrate

- root and portable agent contracts;
- immutable task contracts;
- executable constitutional invariants;
- explicit policy manifest;
- untrusted-contribution CI;
- trusted-integrator separation;
- deterministic build and public disclosure audit;
- GitHub Pages, container, package, and release workflows;
- desired hosting and branch-governance configuration.

## Identity

Catalog and frontier identity derive from accepted content and policy state, not deployment URL. A local node, mirror, and `epistemedia.com` can expose different links while representing the same accepted knowledge state.

## Limitations

- DNS records and production runtime accounts remain external authority until directly verified and recorded.
- Package and MCP Registry publication require publisher identity configuration.
- The initial public realm describes Epistemedia itself; external knowledge realms follow through accepted tasks.
- A successful build verifies reproducibility and interface consistency, not the truth of represented source content.
